## 3. 模块任务与事件队列模型

```mermaid
flowchart TB
    subgraph ISR["中断/硬件层"]
        UART_ISR["UART0 RX 中断<br/>UART0 TX 中断/轮询"]
        Timer2_ISR["Timer2 1ms tick<br/>驱动 soft_timer"]
    end

    subgraph RXPath["接收侧"]
        RecvQ[("receive_queue")]
        RXTask["receive_task (P4)<br/>module_handle_receive_event"]
    end

    subgraph SendPath["发送侧"]
        SendQ[("send_queue")]
        TXTask["send_task (P3)<br/>module_handle_send_event"]
    end

    subgraph ModuleTimers["模块定时器"]
        PollTimer["poll_timer 200ms<br/>EVENT_PERIODIC_SEND"]
        TickTimer["tick_timer 100ms<br/>EVENT_TICK"]
        GapTimer["gap_timer<br/>EVENT_BUS_IDLE"]
    end

    UART_ISR -->|帧收完| RecvQ
    Timer2_ISR -->|soft_timer callback| TXTask

    PollTimer -->|入队| SendQ
    TickTimer -->|入队| SendQ
    GapTimer -->|入队| SendQ

    SendQ --> TXTask
    RecvQ --> RXTask

    RXTask -->|EVENT_RX_FRAME| RXTask
    RXTask -->|EVENT_AC_RX| SendQ
    TXTask -->|sender_send| UART_ISR
```

事件类型对照：

```mermaid
flowchart LR
    E1["EVENT_PERIODIC_SEND<br/>周期轮询/扫描"]
    E2["EVENT_RX_FRAME<br/>收到完整帧"]

    E5["EVENT_TICK<br/>100ms 心跳"]
    E6["EVENT_BUS_IDLE<br/>帧间隔结束可发下一帧"]
    E7["EVENT_AC_RX<br/>AC 接收解析后通知发送状态机"]
    E8["EVENT_SEND_FRAME<br/>外部投递一帧发送"]
```

## 4. 发送路径详细流程

```mermaid
flowchart TD
    StartSend["需要发送一帧<br/>ac_module_send_frame() / module_send_frame()"] --> InTask{"已在 send_task?"}

    InTask -->|否| Q["EVENT_SEND_FRAME 入 send_queue"]
    Q --> TXTask["send_task 取出事件"]

    InTask -->|是| Direct["直接调用 sender_send()"]

    TXTask --> Direct

    Direct --> S1["sender_send(frame, len, priority)<br/>CMD 帧进 cmd_ring<br/>普通帧进 norm_ring"]
    S1 --> S2["sender_pump()"]

    S2 --> BusIdle{"bus_is_idle()?"}
    BusIdle -->|否| WaitBus["等 EVENT_BUS_IDLE 再 pump"]
    BusIdle -->|是| S3["取 CMD 优先 / 普通帧"]
    S3 --> S4["bus_mark_busy()<br/>RS485 切到发送方向<br/>PB5/PB6 置高"]
    S4 --> S5["encoder_tx_enable()<br/>启动逐字节发送"]

    S5 --> S6["UART THR 空中断/轮询<br/>sender_isr()"]
    S6 --> S7{"还有字节?"}
    S7 -->|是| SendByte["encoder_encode_byte()<br/>从 ring 取字节写 UART"]
    SendByte --> S6
    S7 -->|最后一字节已写入| S8{"need_tx_complete?"}

    S8 -->|否| S9["finish_frame_no_tx_complete()<br/>bus_on_thr_empty() -> 空闲"]
    S8 -->|是 RS485| S10["wait_tx_complete=1<br/>启动 sender_poll 软定时器轮询"]

    S10 --> S11["Timer2 tick 驱动 poll_cb<br/>sender_poll_tx_complete()"]
    S11 --> S12{"UART TX_ALL 空?"}
    S12 -->|否| S11
    S12 -->|是| S13["on_tx_complete()"]
    S13 --> S14["bus_on_tx_complete()<br/>bus_mark_idle():<br/>切回接收方向 PB5/PB6 置低<br/>开始 gap 计时"]
    S14 --> S15["tx_done 回调<br/>module_tx_done_from_isr()"]
    S15 --> S16["gap_timer 到期 -> EVENT_BUS_IDLE"]
    S16 --> S17["sender_pump() 发下一帧"]
```

## 5. 接收路径详细流程

```mermaid
flowchart TD
    RStart["RS485 从站应答 / 外部发来数据"] --> R1["UART0 RX 引脚 PB4"]
    R1 --> R2["UART0 RX 中断<br/>RB_IER_RECV_RDY | RB_IER_LINE_STAT"]
    R2 --> R3{"行状态中断?"}

    R3 -->|是| R4["读 LSR 清中断<br/>清空 RX FIFO 丢弃错误数据"]
    R3 -->|否| R5["uart_irq_rx_ready()<br/>从 FIFO 读一个字节"]

    R5 --> R6["uart_decoder 解码<br/>写入 receiver 帧缓冲"]
    R6 --> R7{"帧超时/长度完成?"}
    R7 -->|否| R5
    R7 -->|是| R8["receiver 判定完整帧"]

    R8 --> R9["bus_mark_rx_busy()<br/>保持接收方向；若正在发送则忽略"]
    R9 --> R10["ac_frame_done()<br/>module_rx_frame_done()"]
    R10 --> R11["EVENT_RX_FRAME 入 receive_queue"]
    R11 --> R12["receive_task 取出 EVENT_RX_FRAME"]

    R12 --> R13["module_handle_rx()"]
    R13 --> R14["receiver_read_frame() 取帧"]
    R14 --> R15["rx_log 钩子<br/>[ac evt] rx: ... (rxlog on)"]
    R15 --> R16{"handler->on_rx_frame?"}

    R16 -->|是| R17["ac_module_on_rx_frame()"]
    R17 --> R18["调用 current->protocol_ops->rx_parse(data,len,&ac)"]

    R18 --> R19{"CRC/功能码/寄存器数合法?"}
    R19 -->|否| Drop["丢弃，不锁定"]
    R19 -->|是| R20["更新 ac_state_t<br/>power/mode/set_temp/fan/swing/..."]
    R20 --> R21{"当前未锁定?"}
    R21 -->|是| R22["locked=1<br/>[ac] brand locked id=1"]
    R21 -->|否| R23["已锁定，继续周期轮询"]
    R22 --> R23

    R23 --> R24["ac_module_apply_ac_state()<br/>合并到 gateway_state"]
    R24 --> R25["module_update_state()<br/>有变化则上报网关"]
    R25 --> R26["module_send_event_ex(EVENT_AC_RX, ev)<br/>通知 send_task 跑品牌状态机"]
```

## 6. AC Scan / 品牌锁定详细流程

```mermaid
flowchart TD
    StartScan["ac_module_start_scan()"] --> SS1["locked=0<br/>current=NULL<br/>scan_index=0"]
    SS1 --> SS2["log: [ac] scan start"]
    SS2 --> SS3["module_send_event(EVENT_SCAN_AC)"]
    SS3 --> SQ["send_queue"]

    SQ --> H1["send_task: ac_module_on_scan()"]
    H1 --> H2{"locked || current?"}

    H2 -->|current==NULL 且未锁定| H3["ac_module_scan_next()"]
    H3 --> H4{"遍历 brand_table 找到非空槽?"}
    H4 -->|找到| H5["scan_index = i<br/>current = brand_table[i]<br/>ac_test"]
    H4 -->|一轮没有| H6["scan_index=0<br/>current=NULL<br/>从头再试"]
    H6 --> H5

    H5 --> H7["ac_module_apply_brand_period()<br/>poll_period_ms=2000"]
    H7 --> H8["ac_module_send_scan()<br/>调用 current->on_scan 组帧"]
    H8 --> H9["查询帧: 01 03 00 00 00 07 04 08"]
    H9 --> H10["sender_send() 发送"]

    H10 --> H11["等待从站应答 / 下一周期"]
    H11 --> H12["poll_timer 周期到 -> EVENT_PERIODIC_SEND"]
    H12 --> H13["ac_module_on_periodic_send()"]
    H13 --> H14{"locked?"}
    H14 -->|否| H15["再次 scan_next / 发扫描帧"]
    H15 --> H10
    H14 -->|是| Poll["进入周期轮询"]

    H10 -.->|收到应答| RX["接收路径：rx_parse 成功"]
    RX --> Lock["locked=1<br/>[ac] brand locked id=1"]
    Lock --> Poll

    subgraph Locked["锁定后"]
        Poll --> P1["每 2s 发查询"]
        P1 --> P2["收应答更新状态"]
    end
```

## 7. 锁定后周期轮询详细流程

```mermaid
flowchart TD
    PT["poll_timer 到期<br/>默认周期 2000ms"] --> E1["EVENT_PERIODIC_SEND"]
    E1 --> SQ["send_queue"]
    SQ --> A1["send_task: ac_module_on_periodic_send()"]

    A1 --> A2{"s_ac_auto_tx_enabled?"}
    A2 -->|否| End["不自动发送"]
    A2 -->|是| A3{"locked?"}

    A3 -->|否| Scan["扫描下一个品牌"]
    A3 -->|是| A4["ac_state_from_gateway()<br/>当前 gateway_state -> ac_state"]
    A4 --> A5["ac_module_run_state_machine(AC_EV_POLL,&ac)"]
    A5 --> A6["调 ac_test state_machine()"]

    A6 --> A7["组查询帧<br/>01 03 00 00 00 07 04 08"]
    A7 --> A8["ac_module_send_frame()<br/>sender_send(CMD)"]
    A8 --> A9["发送到 RS485"]
    A9 --> A10["等待从站应答"]

    A10 -->|收到 01 03 0E ...| RX["接收路径 rx_parse"]
    RX --> B1["AC_TEST_EV_RX_RESP"]
    B1 --> B2["ac_module_apply_ac_state()<br/>更新网关状态"]
    B2 --> B3["module_send_event_ex(EVENT_AC_RX, ev)"]
    B3 --> B4["send_task: ac_module_run_state_machine(AC_TEST_EV_RX_RESP)"]
    B4 --> B5["state_machine 返回无帧<br/>next_period_ms=2000"]
    B5 --> B6["module_set_poll_period(2000)"]
    B6 --> WaitNext["继续等下一周期"]
```

## 8. 网关控制命令 / 状态同步流程

```mermaid
flowchart TD
    Cmd["上位机 / BLE / 网关状态事件"] --> C1["module_send_gateway_cmd()<br/>或 module_send_state_sync()"]
    C1 --> C2["EVENT_GATEWAY_CMD 入 send_queue"]
    C2 --> C3["send_task: ac_module_on_gateway_cmd()"]

    C3 --> C4{"带完整 state?"}
    C4 -->|是| C5["self->base.state = *state<br/>log state sync"]
    C4 -->|否| C6["gateway_module_state_get()<br/>取当前状态"]
    C6 --> C7["按 cmd 修改 power/mode/set_temp/fan/swing"]

    C5 --> C8["ac_state_from_gateway(state,&ac)"]
    C7 --> C8
    C8 --> C9["ac_module_run_state_machine(AC_EV_STATE_SYNC,&ac)"]
    C9 --> C10["调品牌 state_machine()"]
    C10 --> C11["构造写控制帧 0x10<br/>写 5 个寄存器"]
    C11 --> C12["ac_module_send_frame() 发送"]
    C12 --> C13["等待从站 0x10 写回执 / 下轮读回确认"]
```

## 9. AC 状态更新与上报流程

```mermaid
flowchart TD
    S1["收到 AC 应答<br/>rx_parse 更新 ac_state_t"] --> S2["ac_module_apply_ac_state()"]
    S2 --> S3["gw = self->base.state<br/>保留非 AC 字段"]
    S3 --> S4["ac_state_to_gateway(ac,&gw)<br/>覆盖 AC 字段"]
    S4 --> S5["ac_module_update_state(&gw)"]
    S5 --> S6{"与当前 state 有变化?"}
    S6 -->|无变化| S7["不上报"]
    S6 -->|有变化| S8["self->base.state = *new_state"]
    S8 --> S9["module_publish_state()"]
    S9 --> S10["gateway_module_state_update(module_id,&state)"]
    S10 --> S11["通知 debug / BLE / 其他观察者<br/>[gw] module=0 power=1 ..."]
```
